# So what now?

A practical, honest guide for working web developers (frontend, backend, devops, QA) on getting ready for agentic AI: what works today, what needs a human, what can be automated, what to learn next, and how hiring really looks.

Written from real enterprise delivery. No hype, no denial.

- **Read it:** https://easingthemes.github.io/so-what-now/
- **Source:** every page is a Markdown file in [`content/`](content/).

## Run the site locally

```bash
cd website
npm install
npm run dev
```

## Contributing
